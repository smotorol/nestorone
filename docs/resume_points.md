# 이력서/면접 정리 문구

이 문서는 이력서나 포트폴리오에 바로 붙여 넣을 수 있을 정도로 구체적이되 과장되지 않게 정리한 문구 모음이다.

## 이력서 핵심 문장

- Oracle XE 기반 주문/재고 미니 시스템을 설계하고 `PL/SQL 패키지`에 주문 생성·취소·재고 차감/복구 로직을 구현해 트랜잭션 일관성을 확보
- `ASP.NET Core Web API + Oracle.ManagedDataAccess` 구조로 Oracle 프로시저 호출 API를 설계하고 공통 응답/예외 처리 구조를 정리
- `WinForms` 클라이언트에서 상품 조회, 주문 등록, 주문 취소, 관리자 재고/오류 로그 확인 흐름을 구성해 서버-DB 연동 시나리오를 구현
- `ORDER_DATE` 기반 조회 병목을 가정해 복합 인덱스와 월별 RANGE 파티셔닝 예시를 설계하고 실행계획 확인 포인트를 문서화
- `Data Pump(expdp/impdp)` 기준으로 테스트 데이터 삭제 후 복구 시나리오를 정리해 개발 환경 수준의 백업/복구 실습 경험을 포트폴리오화

## 1분 자기소개 예시

이 프로젝트는 Oracle DB와 C# 기반 서버/클라이언트 경험을 한 번에 보여주기 위해 만든 최소 실전형 주문/재고 시스템입니다. 단순 CRUD 대신 주문 생성과 취소, 재고 차감과 복구, 오류 로그 적재 같은 핵심 로직을 Oracle PL/SQL 패키지에 넣었고, ASP.NET Core Web API는 그 로직을 호출하는 얇은 서비스 계층으로 설계했습니다. WinForms에서는 상품 조회, 주문 등록, 주문 취소, 관리자 이력 조회 흐름을 구성했고, 추가로 주문일 기준 인덱스와 월별 파티셔닝, Data Pump 복구 시나리오까지 포함해 Oracle 실무 포인트를 설명할 수 있게 만들었습니다.

## 포트폴리오 핵심 문장

- Oracle PL/SQL 패키지 중심으로 주문 생성/취소와 재고 반영 트랜잭션을 구현한 미니 주문/재고 시스템
- ASP.NET Core Web API와 Oracle.ManagedDataAccess를 사용해 Oracle 비즈니스 로직을 안전하게 노출하는 구조 설계
- WinForms 기반 운영 화면으로 상품 조회, 주문 처리, 재고/로그 조회 흐름 구성
- 날짜 범위 조회 성능을 고려한 복합 인덱스 및 월별 RANGE 파티셔닝 설계 경험 정리
- Data Pump 기반 백업/복구 시나리오까지 포함한 Oracle 실무형 포트폴리오 프로젝트
